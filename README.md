# Riftroom Draft Lab

Draft-Werkzeug für League-of-Legends-Teams: Champion-Pools, Übungs-Draft gegen den Computer, Ban- und Pick-Vorschläge, Spielplan mit Zeitleiste und Best in Slot. Auf Deutsch und Englisch.

Die Seite läuft komplett im Browser. Team-Daten bleiben im Browser des jeweiligen Nutzers, es gibt kein Tracking. Nur wer einen Live-Raum nutzt, verbindet sich mit Supabase (Frankfurt); gespeichert wird dort nur der Draft-Stand, ohne Login, und nach einem Tag ohne Änderung gelöscht. Winrates (Emerald+, Solo/Duo) kommen von Lolalytics und werden täglich in `data/meta.json` aktualisiert.
